## Servidor Local / Localhost
- Cuando el usuario requiera el servidor local, ejecutar `npx http-server . -p 8080`.
- La URL local principal es: `http://localhost:8080`

## Directrices del Proyecto
1. **Preservar estructura de datos**: Al modificar `data.js`, mantener intacta la estructura de objetos JSON y la codificación de caracteres.
2. **Interactividad UI**: Cualquier cambio en `index.html` debe mantener el estilo premium, responsive y funcional existente.
